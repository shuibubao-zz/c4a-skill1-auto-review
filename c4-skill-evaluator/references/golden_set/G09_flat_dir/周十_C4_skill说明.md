# 班级提交评审助手

一句话：本技能用于扫描一个装满 C4 技能提交的文件夹，输出每位作者的完整性与质量评审报告。

## 使用场景

课程助教收上来一个班的技能提交（每人 5 份左右文件，命名 `姓名_C4_内容.扩展名`），
需要快速判断：谁缺了什么、谁的内容只有关键词没有真东西。人工逐份翻要一晚上，
这个工具跑一遍出全班报告。

## 输入与输出

输入一个文件夹路径（里面是各位作者的提交文件，支持嵌套子目录），
输出一份 Markdown 评审报告（另可选导出 Excel 摘要表）。

## 运行方式

```bash
python reviewer.py 待评文件夹 --out ./reports
```

## 安装

```bash
pip install pyyaml openpyxl   # 均为可选：没有 pyyaml 走内置解析器，没有 openpyxl 只出 Markdown
```

## 环境要求

Python 3.9+；无强制第三方依赖（评分标准用内置迷你解析器读取）。

## 预期输出

每位作者一节，包含：完整性 5 槽位（逐项带证据锚点）、质量四条件评级（✅/⚠️/❌）、
0-100 综合分与改进建议。示例：输入一个含 2 位作者的文件夹，应输出含 2 节作者详情的报告。

## 边界情况

- 空文件夹：输出"未发现提交"，正常退出
- 文件为 0 字节：视为未提交，不因文件名存在而给分
- 文件名无作者前缀：回退按父目录名分组，报告会标注置信度

## 泛化

槽位定义与检测信号全部外置在 YAML 评分标准里，改评分标准不改代码即可适配其他
场景（如评审数据分析作业、评审文档提交）。换一个 rubric 文件就能复用整条流水线。
