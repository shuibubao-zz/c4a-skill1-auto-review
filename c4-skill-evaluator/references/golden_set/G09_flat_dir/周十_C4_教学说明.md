# 周十_C4_评审助手 教学说明

## 上手三步

1. 安装（可选依赖）：`pip install pyyaml openpyxl`——不装也能跑，只是少了 Excel 输出
2. 环境要求：Python 3.9+，无强制第三方依赖
3. 运行：`python reviewer.py 待评文件夹 --out ./reports`

## 注意事项

- 待评文件夹里的文件建议按 `姓名_C4_内容.扩展名` 命名，作者识别最准
- 0 字节文件会被当作未提交，先检查有没有导出失败的空文件
- 报告默认输出 Markdown；需要 Excel 摘要再装 openpyxl

## 常见坑

- 传了单个文件路径而不是文件夹 → 程序会明确报错，不会静默给空报告
- 中文文件名在部分终端显示乱码 → 输出文件本身是 UTF-8，用编辑器打开即可

## 扩展

想评审其他类型的作业？槽位定义集中在 `SLOTS` 常量里，改这一个字典即可适配，
不用动主流程。
